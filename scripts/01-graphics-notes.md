# Заметки по графике к сценарию №1 (для монтажа)

Технические детали, которые убраны из сценария, чтобы он читался проще.

## Арт-дирекция графики (motion language)

Решения зафиксированы один раз и действуют на весь ролик. Так графика выглядит как сделанная одной рукой (скилл `motion-art-direction`).

| Параметр | Выбор |
|---|---|
| Тон | Спокойно-чёткий: уверенный, деловой, без «игрушечных» эффектов (деньги и бизнес) |
| Личность движения | Corporate: 200–400 мс, без отскоков |
| Основная кривая | `cubic-bezier(0.2, 0, 0, 1)` для появления, она же для ухода. Выход чуть быстрее входа |
| Базовая единица времени | 0,2 с: появление 0,2, крупные перемещения 0,4 |
| Задержка внутри группы | 60 мс |
| Перемещение | До 24 px, масштаб 0,96 → 1,0, отскок не больше 2–3% |
| Переходы между кадрами | Только зум сквозь экран и мягкое затемнение. Без шторок и вращений |
| Пауза после действия | Не меньше 0,3 с покоя перед следующим |
| Один герой в кадре | Всегда один: на экране гостя это ставка, на экране официанта кнопка |
| Единственный «вау» | Переход из планшета в зал на 24–28 с |

**Иерархия движения:** герой (то, о чём говорит Никита прямо сейчас) движется смело и медленнее остальных. Поддержка (подписи, плашки) короче и уходит из кадра, не отвлекая. Фон (свечение, эквалайзер) почти незаметен.

**Что не анимируем:** текст, пока его читают, лишние контуры, цифры на экране. Две графики одновременно не больше.

**Одинаковые приёмы в разных сценах** (повтор создаёт ритм): видоискатель на QR в сценах 3–6 и 40–42 с; жёлтая монета в сценах 20–24 и 28–34 с; логотип BB пульсирует в сценах 34–40 и 42–45 с.

## Экраны телефона и планшета как инфографика

Все интерфейсы в бренд-цветах: чёрный фон `#050505`, карточки `#111111`, жёлтые акценты. Названия треков вымышленные, имён артистов и обложек нет.

**Экран гостя (6–10 с):**
1. Меню заведения: логотип BB, название бара, поиск. Вводится слово, список из трёх треков: «Ночной маршрут», «Мелодия №7», «Танцпол».
2. Выбор ставки: три чипа, один выбран. Суммы `[NEED: согласовать суммы; в презентации виден пример 1 000 ₽]`.
3. Оплата: «СБП» и «Карта», нажатие.
4. Подтверждение: жёлтая галочка «Заказ принят», «В очереди: 3».

**Экран официанта (14–20 и 24–28 с):** заголовок «Заказы», счётчик «На подтверждении: 3», карточки «Мелодия №7» (метка «Не по формату»), «Ночной маршрут», «Танцпол». У каждой кнопки «Принять» (зелёная) и «Отклонить» (красная). Отклонение: красная вспышка, карточка уезжает влево. Принятие: карточка зеленеет, появляется значок «играет».

**Уведомление гостю (20–24 с):** «Ставка отклонена. Деньги вернулись на карту».

Чтобы нарисовать точно, нужны скриншоты реального интерфейса (в презентации виден экран панели администратора) `[NEED]`.

## Готовые блоки HyperFrames для сборки

Найдены через каталог HyperFrames (скилл `hyperframes-registry`). Устанавливаются командой `npx hyperframes add <название>` и правятся как обычный код: цвета и шрифты берём из палитры выше.

| Блок | Где использован |
|---|---|
| `bottom-up-letters` | Заголовок хука, 0–3 с |
| `camera-scan-gate` | Видоискатель на QR, 3–6 и 40–42 с |
| `lt-kicker-name` | Плашка «Никита Павлов», 3–6 с |
| `device-frame-stage` | Макет телефона для экрана гостя, 6–10 с |
| `gesture-tap` | Нажатие на оплате, 6–10 с |
| `icon-swap` | Подсветка значка официанта, 10–14 с |
| `press-ripple` | Курсор на кнопках планшета, 14–20 и 24–28 с |
| `notification-stack` | Уведомление об отклонении, 20–24 с |
| `zoom-through-transition` | Переход из планшета в зал, 24–28 с |
| `waveform` | Эквалайзер в зале, 24–28 с |
| `icon-morph-beat` | Монета в формуле, 28–34 с |
| `caption-clip-wipe`, `caption-editorial-emphasis` | Субтитры всего ролика |

Что руками, потому что готового нет: деление суммы на процент (34–40 с), экраны гостя и официанта (содержимое), финальная карточка.
